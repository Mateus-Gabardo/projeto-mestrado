# Artigos e fontes consultadas

Armazene aqui os PDFs e materiais relacionados ao inventário de araucárias. O catálogo com uma descrição breve de cada artigo está em `../indice_materiais.md`. Registre cada obra citada em `../../referencias/referencias.bib`.

O material mantido nesta pasta deve estar relacionado à identificação de araucárias, copas individuais, estruturas reprodutivas, imagens aéreas ou georreferenciamento.
